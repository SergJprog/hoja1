# hoja 4

Hoja de trabajo número 4
Este pequeño proyecto contiene algunos de los lugares turisticos de Quetzaltenago

Las mejoras incluidas dentro de este proyecto son las siguientes:

 1. Se agregó una página contactactanos, donde se incluyo un formulario.
 2. En esta página también se muestran comentario de personas ficticias.
 3. Al llenar el formulario y enviarlo se envia un mensaje en pantalla que indica el envio satisfactorio de la información.
 4. La información enviada se muestra en la consola.
